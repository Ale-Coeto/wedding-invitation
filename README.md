# Wedding Invitation
This project allows an admin to add guests and get a unique link to access their invitation.
- Each guest gets a personalized invitation
- They can confirm their assistance as well as dietary restrictions
- Admin page allows wedding manager to add or edit guests and view responses

# Tech stack
Built with:
- [React](https://reactjs.org/)
- [Next.js](https://nextjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Prisma](https://www.prisma.io/)
- [Tailwind CSS](https://tailwindcss.com/)
- [TRPC](https://trpc.io/)
- [T3](https://create.t3.gg/)
- [Google OAuth](https://developers.google.com/identity/protocols/oauth2)
  
Deployed with [Vercel](https://vercel.com/)
